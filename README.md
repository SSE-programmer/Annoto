# Annoto

SPA-приложение для создания статей и аннотирования текста.
Построено на Angular 21, без сторонних UI-библиотек — вся функциональность
реализована средствами Angular, TypeScript, HTML и CSS.

DEMO: https://annoto-2026.vercel.app/

---
## Принципы

- **Standalone-компоненты** — без NgModules.
- **Без Zone.js** — используется `provideZonelessChangeDetection()`.
- **Lazy loading** — страницы загружаются по маршруту.
- **OnPush** — стратегия обнаружения изменений по умолчанию.
- **Signals + RxJS** — сигналы для состояния компонентов, RxJS для асинхронных потоков.
- **Разделение ответственности** — компоненты, сервисы, директивы, утилиты.
- **Без сторонних библиотек** — весь UI, модалки, тултипы, аннотации реализованы с нуля (DOM API, Range API, TreeWalker, Renderer2 и т.д.).

## Возможные улучшения

- Добавление кнопки для прокрутки страницы вверх
- Реализация пересекающихся аннотаций (немного усложнится алгоритм рендера. При пересечении необходимо дробить тег аннотации в каждом месте пересечения на 2 части)
- Реализация редактирования текста статьи без удаления всех аннотаций (Предположу, что при редактировании текста необходимо смотреть разницу и, при удалении текста, смотреть, было ли затронуто удаление частей аннотаций. Если было, то пересчитывать границы аннотаций, редактировать)

## Запуск

### Требования

- Node.js 20+
- npm 11+

### Установка и запуск

```bash
npm install
npm start
```

### Сборка

```bash
npm run build
```

### Тесты

```bash
npm test
```
